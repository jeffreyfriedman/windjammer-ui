# ADR-0005: Web: WebGPU primary, WebGL2/CPU fallback, SSR semantic skeleton with hydration adoption

- **Status:** Proposed
- **Date:** 2026-10-11
- **Related:** `docs/VISION_2026.md`, `docs/vision/SAMPLES.md`, `docs/compiler-requests/README.md`

## Context
WebGPU ships in Chrome/Edge 113+, Safari 26 (Sep 2025), Firefox on Windows and Apple Silicon macOS (secondary sources). `vello_hybrid` (WebGL) is documented as not production-ready. Spike: wgpu+vello+parley wasm is 0.58 MB brotli (unexecuted, without bindgen glue or fonts). Canvas apps are invisible to crawlers.

## Options
A. WebGPU only. B. WebGPU + own quad painter on WebGL2 + CPU fallback. C. DOM render backend for content sites.

## Decision (recommended)
**B**, plus SSR: the server renders the semantic tree to real HTML; the client adopts those nodes as its DOM projection. Size budgets: counter < 400 KB brotli, text app < 2.0 MB. Single-threaded v1 (no cross-origin isolation requirement). Option C deferred.

## Consequences
Two painters to maintain (Vello and quad); hydration adoption logic; unverified in browsers (M0).

## Decision needed from: project owner
Approve budgets; approve own WebGL2 painter if `vello_hybrid` is not ready by M3.
